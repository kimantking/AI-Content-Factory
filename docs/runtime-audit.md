# 실사용 연결 점검 (2026-09-08)

## 이번 변경
- 제작 워커가 웹 설정과 같은 암호화 저장소에서 Google/ElevenLabs 키를 읽음.
- 캠페인 작업공간별 키 범위를 유지하고 작업 종료 시 컨텍스트 복원.
- 선택한 목소리를 DB에서 다시 읽음. 프로세스 전역 설정 변경 제거.
- 테스트용 가짜 Voice ID 제거. 미선택이면 제작 전에 명확하게 실패.
- 실패가 이미 끝난 작업에 자동 복구 중이라고 표시하던 문구 제거.
- 플랫폼 변환 단계 변경을 호출 전에 커밋해서 진행 화면에 표시.
- 체크포인트 생성 이전 실패도 재시작 가능.
- Trafilatura 2.0.0 (Apache-2.0)로 이미 내려받은 HTML 본문 추출.
- CI에 실사용 모드의 저장 키/목소리 전달 및 기존 공급자 HTTP 계약 검사 추가.

## 검증 범위
CI는 테스트용 키와 HTTP 응답으로 공급자 계약을 확인하고 FFmpeg로 실제 파일을 합성한다.
사용자 PC의 실제 API 키, 요금제, 모델 접근 권한, 한국어 음성 품질을 검증한 것은 아니다.
무인 SNS 게시 및 통계 어댑터는 여전히 미구현 구간이 있으므로 전체 자동화 완료로 간주할 수 없다.
이전 한국어 fallback은 원본이 영어일 때 일반적인 문장으로 대체하므로 요청한 웹툰의 내용/품질 보장은 별도 과제다.
실제 자격 증명으로 콘텐츠 한 편의 대본, 음성, MP4를 확인해야 실사용 완료로 판단할 수 있다.

## 무료 후보
- Pexels API: 배경 사진/영상, 200회/시간 및 20,000회/월 기본 한도. 계정 키와 출처 표기 조건 확인 필요.
  https://www.pexels.com/api/documentation/
- Gemini API 무료 구간: 대본/분석 후보. 모델별/프로젝트별 한도가 다르며 Veo 무료 사용을 의미하지 않는다.
  https://ai.google.dev/gemini-api/docs/rate-limits
- Trafilatura: 키 없이 로컬 HTML 본문 추출. 이번 변경에 통합.
  https://github.com/adbar/trafilatura
- Piper: 로컬 TTS 후보. 한국어 음성 가용성·개별 음성 라이선스를 확인하기 전 ElevenLabs 대체로 설치하지 않음.
  https://github.com/OHF-Voice/piper1-gpl

Pexels는 AI 생성 영상 API가 아니라 기존 스톡 자료 검색 API다. 이번 변경에서는 외부 계정을 만들거나 임의의 목소리로 유료 합성하지 않는다.
