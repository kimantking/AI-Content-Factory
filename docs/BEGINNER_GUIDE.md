# BEGINNER GUIDE (초보자 안내)

AI Content Factory는 주제와 참고자료만 주면 리서치 → 대본 → 영상 → 검수 → 게시까지
자동으로 진행합니다. 내부의 Agent / LangGraph / Queue / Prompt Registry / Provider
같은 개념을 몰라도 사용할 수 있습니다 (UI 모드 기본값 `BEGINNER`).

## 처음 한 번 (설정)

`/setup` 8단계: 워크스페이스 → 브랜드 → SNS → 클라우드 AI(선택) → 로컬 AI(Ollama)
→ 스타일 → 예산/안전 → 테스트 실행. 중간에 나가도 자동 저장되어 이어서 할 수 있습니다.

## 만들기 (`/create`)

1. **주제** 입력
2. **참고자료 URL** 추가 (선택)
3. **작업 모드**: 학습+만들기 / 콘텐츠 만들기 / 학습만 하기 / 자료만 저장
4. **SNS**: 각 플랫폼·형식을 클릭해 `사용 안 함` / `제작만` / `제작 + 게시` 로 전환
5. **품질**: 빠르게 / 균형 / 고품질 / 최고품질
6. **예상 비용** 확인 — 확인되지 않은 항목은 "UNKNOWN"으로 정직하게 표시됩니다.
   로컬 AI 작업은 "LOCAL PROCESSING · API ₩0" (컴퓨터 자원은 사용)
7. **콘텐츠 만들기**

## 결과 보기

- **콘텐츠(`/library`)** — 지금까지 만든 모든 콘텐츠. 과거 버전, 레거시 콘텐츠 포함.
- 카드/표 전환, 검색, 필터, 페이지네이션.
- 콘텐츠 상세: 미리보기(실제 영상 재생), 대본, 플랫폼 버전, 미디어, 참고자료,
  학습 근거, 검수, 게시, 분석, 수익, 변경 이력.

## 학습만 하기 (`/learn-studio`)

좋은 영상·글·자료의 URL을 넣으면 AI 제작팀이 패턴(Hook / Story / 편집 / 자막 등)을
학습합니다. **캠페인·영상·게시는 만들지 않습니다.**

## 검수 (`/governance`)

게시 전 권리·사실·표시·저작권을 확인합니다. 문제가 있으면 "게시 전에 확인이
필요합니다" 화면과 함께 원인·조치 버튼(예: 음악 교체)이 나옵니다. 법적 판단이
필요한 항목은 AI가 임의로 승인하지 않습니다.

## 로컬 AI

Ollama(`gemma3:4b`)가 실행 중이면 분류·태깅·요약 등 가벼운 작업은 로컬에서 처리해
API 비용을 아낍니다. Ollama가 꺼져 있어도 앱은 정상 동작합니다
(`ALLOW_CLOUD_FALLBACK` 설정에 따라 클라우드로 대체하거나, LOCAL_ONLY면 명확히
실패를 알립니다).
