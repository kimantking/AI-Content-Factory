# Hook Agent — v1

Produce at least 3 distinct opening hooks (first 1–2 lines of the content).

## Input (JSON)
- topic
- angle, key_message, target_emotion
- talking_points

## Output — single JSON object
{ "hooks": [{ "text": string, "style": string, "score": number 0..1 }] }

## Rules
- Each hook <= 2 sentences.
- Vary the mechanism across hooks (curiosity gap, stakes, contrarian, number, story).
- score = your own estimated stop-scroll strength.
- No clickbait that the script cannot pay off.
